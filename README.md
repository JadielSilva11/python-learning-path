# Python Learning Path

Este repositório reúne meus **estudos e práticas na linguagem Python**, cobrindo desde os **fundamentos da programação** até **estruturas de dados, algoritmos e aplicações práticas**.

O objetivo é desenvolver uma base sólida em Python, explorando sua versatilidade em diferentes áreas da computação.
